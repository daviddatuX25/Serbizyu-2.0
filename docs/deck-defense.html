02 · Problem
SERBIZYU — CAPSTONE DEFENSE

Every provincial transaction today is a trust gamble.

No escrow, no recourse

Buyers lose deposits. Workers finish the job and are never paid. There's no rating history — every deal is a coin flip.

Pushed into unindexed chats

Facebook restricts service listings. Providers scatter into Messenger threads — no pricing, no calendar, no identity check.

Cost and fear block adoption

Data load, not signal, is the real barrier. Over 90% of informal providers fear BIR registration and stay invisible.

This is not a skills gap. It is an access gap. 02 / 16

05 · Architecture
SERBIZYU — CAPSTONE DEFENSE

Four doors in. One escrow core.

Every entry point — app, SMS, kiosk, or a face-to-face QR scan — feeds the same Serbizyu Core and the same double-entry ledger. No side channel skips the trust layer.

1Buyer pays → funds are held, never released to the servicer up front.
2Both sides confirm completion — dual confirmation, not a single tap.
3Escrow releases. Online, Xendit settles digitally. Offline, cash is recorded by the Cloud Truth Boundary the moment signal returns.
Four doors in, one escrow core that protects every peso. 05 / 16

12 · Model
SERBIZYU — CAPSTONE DEFENSE

No BIR form. No upfront cost. No smartphone required.

Lane 1 · Starter
Phone + ID verified

Capped payouts. Instant onboarding. No tax paperwork. Best for low-volume sellers testing the platform.

13 · Technology
SERBIZYU — CAPSTONE DEFENSE

Built for offline-first. Powered by modern web.

Frontend
Laravel + Inertia Svelte 5 Tailwind CSS PWA-ready
Responsive web app that works on low-end smartphones. Service workers for offline-capable Quick Deal flows.
Escrow Ledger
MySQL Double-entry Xendit API
Every transaction logged as debit/credit pair. 0% drift by design. Offline cash recorded on reconnect via Cloud Truth Boundary.
Backend
PHP 8.x Laravel RESTful API SMS Gateway
API-first architecture. SMS integration with Semaphore for feature-phone users. Queue workers for async escrow release.
Security & AI
K-Means + BGE OTP Auth Rate limiting
K-Means for provider categorization. BGE embeddings for smart search. OTP ensures every identity is phone-verified.
Tech chosen for reliability, reach, and provincial connectivity. 13 / 16
