## Universal n8n Architectural Primitives Proven Across All 100 Cases

Across all 100 municipal business use cases, the Serbizyu 2.0 engine enforces the identical **5 core workflow primitives**:

| Primitive | Real-World Municipal Purpose | Engineering Implementation |
| :--- | :--- | :--- |
| **1. Parallel Fork** | Dispatches simultaneous activities so providers don't sit idle (e.g. Technician triages on-site while Courier drives to hardware store). | Concurrently creates active child orders; no parent blocking. |
| **2. Dependency Join Gate** | Prevents assembly or irreversible labor until physical parts or predecessor deliverables arrive on-site. | Managed via `work_step_dependency_gates`; unblocked asynchronously by transactional outbox events. |
| **3. Customer Approval Gate** | Halts work for human-in-the-loop authorization before scope overage, price changes, or irreversible cuts. | UI push notification with photo comparison; transitions gate to `unblocked` upon citizen tap. |
| **4. Diagnostic Pause** | Protects technicians when hidden damage is discovered on-site. | 30-min TTL pause with explicit choice: *Approve expanded scope* OR *Exit cleanly with paid diagnostic fee*. |
| **5. Sidecar Errand** | Allows on-demand mid-job procurement (e.g. ran out of screws or extra sarsa) without voiding the main contract. | Spawns an independent child Need funded via micro-variance; original contract remains pristine. |
