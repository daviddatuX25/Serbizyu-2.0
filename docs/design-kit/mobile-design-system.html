Canonical Node Card Architecture — Universal Standard for Work & Deal Chains

Reconciles the structural design conflict between Work Pipelines and Deal Chains. All nodes share the exact same physical dimensions, connection port mechanics, and light-theme canvas integration, while cleanly adapting between Bound Listings (real photos), Work Milestones (action glyphs — never empty photo voids), Logic Gates (amber caution indicators), and Open Slots (dashed unassigned states).

Universal Node Anatomy (4 Integrated Zones)
1. Type & Status Strip
Category pill (PART / RIDER / LABOR / STEP), Price badge (₱180) or Duration (15m), and subtle unassign/remove icon [✕].
2. Visual Hero Zone
Real photo cover (54px) for catalog listings, OR Category Action Glyph box [📋 / 🔧] for labor steps. Never an empty photo void!
3. Identity & Specs
Bold 10.5px Title, 8.5px Provider/Requirement subtext, and status pill (In Stock, En Route, 30-Day Seal).
4. Ports & Controls
Left input port (●), Right output port (●) with attached [+] quick-chain handle, and Slot Actions when unassigned.

Universal Rules for Node Cards Across Serbizyu 2.0:
  • Consistent Width ($108\text{px}$): Every card across Work Pipelines and Deal Chains shares the same geometry so layouts never stutter or break.
  • Real Photography for Bound Listings: When an actual catalog product, courier fleet, or technician is assigned, show crisp $54\text{px}$ photo headers.
  • Zero Photo Voids for Work Steps: Labor milestones are actions, not physical stock. They use clean Action Glyph headers with duration badges (e.g. STEP 2 · 20m) and evidence requirements.
  • Dedicated Free Slot State: Unassigned slots feature dashed amber borders and direct [ ⇄ Fill Slot ] and [ 🛠 Reshape ] buttons.
  • Quick-Chain Handle ($[+]$): Every node's output port hosts the attached $[+]$ button for instant downstream node chaining.
Universal 3-Tier Flow Canvas Interaction Standard
Platform Invariant

Reconciles how flow canvases (Work Pipelines in Service Request and Deal Chains in Cart/Builder) render across compact forms and interactive exploration. Solves the “elongated node” and “broken card” defects permanently through three strictly isolated tiers:

Tier 1: Compact Inline Preview
Height: 86px viewport.
Node Aspect: 104×58px landscape ratio (never elongated towers!).
Fixed Icon: Top-right [ ⤢ ] pinned to outer .canvas-frame-box so it never scrolls horizontally.
Zero Squishing: Centers naturally, smooth pan/swipe if more nodes added.
Tier 2: Full Mobile Studio Overlay
Viewport: 100% phone screen takeover (.mobile-flow-overlay).
Zero Form Distortion: The form cards (Card 2 & 3) stay untouched and pristine.
Fixed HUD: Bottom toolbelt ([ + Step ], [ Done ]) anchored to overlay frame, never scrolls horizontally.
Interaction: Free touch-panning across dot-grid canvas.
Tier 3: Glovo Drop-Up Bottom Sheet
Trigger: Tapping any node in Tier 1 or Tier 2.
Visual: Signature organic asymmetrical wave cap (.glovo-wave-cap).
Content: Progressive disclosure of itemized deliverables checklist, completion SLA window, and terms.
Actions: Save specs or remove custom milestone.
