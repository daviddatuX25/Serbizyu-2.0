Designer rules

Prefer

  • Icon + text for actions and statuses
  • Real listing photos of the craft or place
  • Tagudin fixtures with exact inclusions and prices
  • One primary verb per screen
  • Serbizyu forest tokens when mapping to shadcn later

Avoid

  • Engineering diary copy inside specimens
  • Left-border status accents
  • Roadmap cards and dead feature buttons
  • Default unmodified shadcn look
  • Color-only meaning or generic “Continue”
