Preview state & implementation notes

Real local capabilities: photo stamping, file selection, supported camera/recording APIs and Leaflet pin placement. No uploads, safety scans, server timestamps, real approvals, payments or durable offline storage. Refresh clears this preview.

The camera shell is throwaway browser-API glue, not the production SDK choice. The app should reuse a reviewed capture library behind one media interface; existing Work upload, privacy and clearance services remain authoritative.

Photo stamps use this device's clock (displayed in Philippine time). They do not prove when imported photos were taken or independently verify a location. Video time is metadata, not a burned-in video watermark. Clip limits here are preview limits only.

“Needs correction” previews a proposed service-Work transition; it is not currently a live A1/A3 backend action.
