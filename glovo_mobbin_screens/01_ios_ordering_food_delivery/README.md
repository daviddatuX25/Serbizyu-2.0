## Flow Overview

The user orders food from a restaurant ('The Dirty Vegans'), customizes menu items with add-ons, provides order notes (allergies/cutlery), configures delivery address and tip, completes phone verification via SMS, tracks the order on an interactive map with real-time driver status, receives delivery confirmation, and is given the option to reorder.
